# Startups

Repositório de apoio à disciplina **Startup**, do curso de **Sistemas de Informação – Graduação**.

Este repositório reúne os materiais utilizados ao longo do semestre, servindo como base para o estudo de empreendedorismo, inovação e desenvolvimento de startups, utilizando metodologias ágeis de validação de negócios, construção de produtos e desenvolvimento de soluções voltadas ao mercado.

---

# 🎯 Sobre a disciplina

A disciplina aborda os principais conceitos relacionados à criação e desenvolvimento de startups, desde a identificação de oportunidades até a validação de modelos de negócio e apresentação de soluções inovadoras.

Durante o semestre serão desenvolvidos conteúdos relacionados a:

* Lean Startup;
* Running Lean;
* Identificação e análise de oportunidades;
* Validação de hipóteses;
* Planejamento de experimentos;
* Desenvolvimento de MVP (Minimum Viable Product);
* Ciclo de vida do cliente;
* Prototipação;
* Pitch de negócios;
* Estudos de caso;
* Desenvolvimento de projetos.

A disciplina possui caráter essencialmente prático, estimulando a aprendizagem baseada em projetos e o desenvolvimento de soluções para problemas reais. 

---

# 🧠 Objetivos de Aprendizagem

Ao final da disciplina o estudante será capaz de:

* compreender os fundamentos do ecossistema de startups;
* identificar oportunidades de inovação;
* aplicar a metodologia Lean Startup;
* elaborar e validar hipóteses de negócio;
* planejar e executar experimentos de validação;
* desenvolver um Produto Mínimo Viável (MVP);
* estruturar propostas de valor para diferentes perfis de clientes;
* comunicar ideias por meio de apresentações (pitch);
* desenvolver soluções inovadoras utilizando metodologias centradas no cliente.
